# Inbox

这里存放 agent 生成的待审核工程记忆摘录。

## 使用规则

- agent 默认只能把候选内容写到这里。
- 用户审核后，再移动到 `architecture/`、`tech-stacks/`、`business-flows/`、`lessons/` 或 `preferences/`。
- 如果候选内容只属于某个项目，不应该归档到 `_agent-memory/`，应该回到项目仓库或项目文档。

## 命名建议

使用 `YYYY-MM-DD-topic.md`，例如：

- `2026-06-01-vue-settings-page-pattern.md`
- `2026-06-01-agent-memory-workflow.md`

## 审核清单

- 是否跨项目可复用？
- 是否包含敏感信息？
- 分类是否准确？
- 是否和现有正式笔记重复？
- 是否需要压缩成更清晰的原则或模式？
